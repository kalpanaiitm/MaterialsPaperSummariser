# Papers Folder

This folder stores research papers used by MaterialsPaperSummariser.

Add PDF papers here when running locally.

Example:

data/
└── papers/
    ├── paper1.pdf
    ├── paper2.pdf
    └── README.md

Do not upload copyrighted papers publicly.

Use:

- Open-access papers
- Your own publications
- Local sample PDFs

This folder remains empty in the public repository.
